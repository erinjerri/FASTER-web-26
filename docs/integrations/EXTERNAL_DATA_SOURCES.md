## Review Requirements

Before any provider is implemented, document:

- API availability and authentication.
- Terms of service.
- Licensing and display rights.
- Rate limits.
- Retention limits.
- Required attribution.
- Whether data can be cached.
- Whether data can be shown publicly.
- Whether data is canonical or supplemental.
